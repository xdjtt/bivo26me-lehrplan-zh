# d1.6 – Beschreiben Sch0-6 und Storen

## 1. Lehrjahr
Sie beschreiben die Funktion von selbst erstellten Lichtsteuerungen: Schema 0, 1, 2, 3, 6. Sie beschreiben die Storensteuerung einzeln für Auf und Ab.

## 2. Lehrjahr
Sie beschreiben die Funktion von selbst erstellten Lichtsteuerungen: Minuterie, Schrittschalter, Passivinfrarotmelder, einfache Schaltuhr, Dämmerungsschalter. Sie beschreiben die Funktion von selbst erstellten Sonnerieanlagen, Gong, Türöffner.
Siehe Leistungsziel a1.1.
